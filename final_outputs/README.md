# Final Outputs

This module builds the three final outputs discussed for PathLearn:

1. Learning review material (`PDF`)
2. Text-image-grounding dataset (`JSONL`)
3. QA benchmark generated by an LLM (`JSON`)

Input expected:
- Processed segment folder (example):
  - `history/case_003`
  - contains `seg_00xx_union.png`, `seg_00xx_text.txt`, `seg_00xx_raw.json`, etc.
- Case background JSON (recommended and required by default):
  - `final_outputs/case_context.template.json`
  - or pass one flexible string with `--background-text`

## Output Formats

### 1) Learning Review PDF
- File: `learning_review.pdf`
- One page per segment
- Uses `seg_00xx_union.png` (no marker image)
- Includes sentence text and segment time range

### 2) Text-Image-Grounding JSONL
- File: `text_image_grounding.jsonl`
- One JSON object per segment
- Includes:
  - segment id, start/end seconds, text
  - image paths (`union`, `all`, `eye`, `mouse`, `eye_attention`)
  - grounding info (`boxes`, `boxes_final`, `eye_points`, `mouse_points`)
  - optional eye-attention image generated from `boxes_final` + `eye`
    - default render mode: boundary overlay (red contour on `union` image, no heatmap)

### 3) QA Benchmark
- File: `qa_benchmark.json`
- `gemini` mode (default): each generation call includes segment `union` image + segment text
- `openai` mode: generated from transcript text
- Contains multiple-choice questions (4 options), answer index, explanation, evidence text

## Usage

Generate all three outputs:

```bash
python3 final_outputs/build_outputs.py \
  --dataset-root history/case_003 \
  --transcript-json videos/example_data/brain/transcription.json \
  --background-text "brain, suspected GBM, surgical resection" \
  --auto-background \
  --refine-text \
  --eye-attention-tier low \
  --output-dir final_outputs/example_data \
  --qa-provider gemini \
  --qa-model gemini-3-flash-preview \
  --qa-count 25
```

Gemini-only QA run:

```bash
python3 final_outputs/build_outputs.py \
  --skip-pdf --skip-grounded \
  --case-context-json final_outputs/case_context.template.json \
  --qa-provider gemini \
  --qa-model gemini-3-flash-preview \
  --qa-count 25
```

Generate only PDF + grounded dataset (skip QA API call):

```bash
python3 final_outputs/build_outputs.py --skip-qa
```

Generate only QA benchmark:

```bash
python3 final_outputs/build_outputs.py --skip-pdf --skip-grounded
```

## Notes

- Gemini QA generation uses `google-genai` and expects `GEMINI_API_KEY` (or `--api-key`).
- On rate-limit errors (`429` / `RESOURCE_EXHAUSTED`), generation retries after 5 seconds by default.
- OpenAI QA generation is still available via `--qa-provider openai`.
- Voice transcription remains backend-agnostic via `processors/voice/VoiceData.py`.
- By default generation refuses missing case background metadata; use `--allow-missing-case-context` to bypass.
- Context window from prior transcript segments is included in generated human/machine outputs and Gemini QA prompt.
- `--auto-background` builds a 3x3 collage from `union.png` screenshots and asks Gemini to summarize one flexible `background_text`.
- `--refine-text` rewrites raw segment transcript into cleaner training-ready text (stored as `text_refined`) while preserving `text_raw`.
- Eye-attention contours are generated in `output_dir/eye_attention/` by default via `final_outputs/gaze_attention.py`.
- Default tier is `low` (larger ROI). Use `--eye-attention-tier high|mid|low` to override, or use `--eye-attention-sigma` and `--eye-attention-quantile`.
- Use `--eye-attention-render-mode boundary_overlay|heatmap_contour` (default: `boundary_overlay`).
- Boundary mode tuning: `--eye-attention-boundary-color`, `--eye-attention-boundary-width`.
- Use `--skip-eye-attention` to disable contour image generation.

## Preview / Verify

Use the reviewer app to validate generated items in browser:

```bash
python3 reviewers/build_review_manifest.py
python3 reviewers/launch_reviewer.py
```

Reviewer supports `yes/no` decisions with exportable decision JSON.
